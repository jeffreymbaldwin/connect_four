# connect_four

A command-line Connect-Four game built in Ruby to practice TDD principles.

## Description

A Connect-Four game played on the command line where two human players can play against each other. The board is displayed in between each turn.

## Purpose


## How to Run

```bash
ruby game.rb
```

## Usage
- Two players take turns placing markers on a 6 x 7 board.
- Enter a number from 1-42 to choose a position to place your marker.
- The game ends when a player wins by getting 4-in-a-row or the game results in a draw.
